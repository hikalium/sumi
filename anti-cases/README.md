各原文は操作者の提示どおりに保存した。原文の文字や記号を保ち、改善例では表記も整理した。
sumi の改善プロンプトと検出結果に沿って書き直し、改善例を同じバイナリで再検査した。
sumi は検出と改善指示を担当し、文章の編集はエージェントが行う。

## 検出と編集の判断

追加した字面は留保を見直すシグナルとして扱う。必要な留保にも一致するため、
検出だけで削除や断定への変更を決めず、読み手が使う事実・条件・範囲を保って編集する。
数値、コマンド、マスク済みの公開範囲、再計算に必要な原データを保つ。
リンクアップから疎通性能を推測したり、方向設定の可能性を実機での発生と断定したりしない。

「未実施」などの留保は助詞を含む文字列で照合し、引用とコードを除外する。
09 と 10 の文末は、必要なもの・対象・条件を具体的に書くため、前後の重複を条件にせず検出する。
句点を含む字面とその丁寧形を照合する。条件や限定を詳しく書き、元の範囲を保つ。

```sh
cargo build --offline --locked
./target/debug/sumi --file anti-cases/01-link-cause.before.md
./target/debug/sumi --check-only --file anti-cases/01-link-cause.after.md
cargo test --test anti_cases
```
