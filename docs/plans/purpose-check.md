# 提案・留保の文の必要性を確認する指示

- 留保、追加検証、条件・限定、注意を扱う 7 規則と、未実施の説明も扱う否定構文の変更提案に、操作者指定の文を加える。
- 文言は「そもそもこの文が文章の目的に照らして必須かどうかを判断し、そうでないなら削除することも検討しなさい」とする。
- 共通のマクロで既存の変更提案に追記し、通常の検出結果、`--check-only`、`--rules` で同じ指示を出す。改善プロンプトにも同じ指示を記載する。
- 必要な事実・条件を保つ既存の指示を維持する。語の言い換えだけを扱う規則と、混在・漢字 1 字の検査は従来の出力を使う。
- 13 組の原文に対する各変更提案、規則の一覧、否定構文、通常出力、無出力モードをテストする。関係のない語の訂正に指示が混ざらないことも確認する。
